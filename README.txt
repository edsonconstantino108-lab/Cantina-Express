CANTINA EXPRESS — CÓDIGOS SIMPLIFICADOS

1. Extraia os ficheiros para a mesma pasta.
2. Abra index.html no navegador.

Ficheiros:
- index.html: estrutura da página.
- style.css: cores, organização e adaptação a telemóveis.
- script.js: cardápio, filtros, carrinho, combos e horários.

O checkout é uma demonstração. Não existe ligação a uma base de dados nem processamento real de pagamentos.
Os produtos e preços podem ser alterados no início de script.js.
